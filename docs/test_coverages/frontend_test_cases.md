- **Edge Case Validation**:
    - **Network Delay**: While the backend is saving, the button shows a "Loading..." spinner and is disabled to prevent double-submission.
    - **Large Text**: Pasting 500 characters into the "Home Address" field; the UI adjusts without breaking the layout.

| `Rekap: import alert` | Excel | Click "Upload" -> File | Success Toast notification | Uploading non-excel file (error toast), large file size (upload progress). |

### 🔍 UX Deep Dive: Grade Rekap
- **Inputs**: User uploads a valid Excel rekap for 30 students.
- **Output Success**: A "Success" toast appears, and the table automatically refreshes to show the new grades.
- **Edge Case Validation**:
    - **Corrupt File**: User uploads a renamed `.txt` file as `.xlsx`. The system shows a "Format file tidak didukung" error instead of a white screen crash.
    - **Partial Data**: Excel only has half the students; system updates those present and notifies the user about missing records.
